# 本地参考材料

这里保存原始测量、用户输入与外部源码参考。材料由本目录的 `.gitignore` 默认忽略, README 和忽略规则本身可进入版本控制。没有明确要求时不提交截图、图像、CPU profile、外部源码或机器路径日志。

本地材料已放入 `local/2026-11-05/`:

- `4k-baseline/`: 原临时评估报告、baseline/controls/profile-run JSON、CPU profile 和当时最后一版脚本。
- `photocraft-v0.20.2/`: 固定版本的研究用源码及原许可证。
- `SOURCE_MANIFEST.json`: 来源版本、文件校验值和用途; 可检查本地材料完整性。

临时原件保留, 不移动或清理用户文件。原脚本保存的是最后一次控制配置, 并非可一键重跑全部基线的正式基准程序。

经核对后可共享的结论已提升到 [4K 评估](../engineering/4K_SELECTION_ASSESSMENT.md) 和 [PhotoCraft 对照](../architecture/PHOTOCRAFT_REFERENCE.md)。这些文档包含必要环境、结果、限制及固定链接, 因此没有本地原件也能理解结论。原始材料不构成性能承诺或自动实施授权。
