# 生成结果添加到画板时适配尺寸

目标是点击 WP 内生成结果的「添加到图层」后，图层适配当前画板。同宽高比铺满。比例不同时等比缩放并居中，完整保留图像。像素边界用整数取整，短边最少为 1 像素。左或上余数向下取整。

## 改动边界

- ADA 画板分支负责区分 Results 行和项目素材入口。结果添加继续使用项目图片读取权限、哈希校验及当前画板绑定。生成请求、原始结果 Artifact、项目素材、常规导入和从图片新建画板不改。
- WP main 负责用于导入的等比适配。WP embedded 负责选择适配策略和调用既有图层历史命令。源色彩采用现有导入与画板色彩接入流程，输出满足当前画板 native RGB8 格式。
- 不改画板自身尺寸、既有图层、存储格式和自动保存规则。添加结果保留来源标记并形成一个可撤销操作。读取或处理失败不添加图层。迟到的结果由现有文档绑定和编辑保护拒绝。
- 按 WP main → integration/embedded → ADA 画板分支顺序固定构建。仅本地验证，不访问生产或调用收费模型。

## 验收

- 小尺寸的同宽高比图铺满整个画板，较大同宽高比图缩小铺满。异比例图完整显示，短边居中且剩余为透明区域。
- 项目素材保留原尺寸。同尺寸生成图避免无必要的重采样。带透明边缘或高位深的输入经 RGB8 适配后可保存并重新打开，来源记录和撤销、重做保持。
- 验证独立设计与实现审查，WP 尺寸与像素断言、embedded 图层命令、ADA 两入口及最终包。至少一次真实浏览器 Worker 或 Canvas 验证。
