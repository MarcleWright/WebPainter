# Color 面板与笔刷交互

2026-11-24 · WebPainter_Dev / codex/dev · 基线 d6a7f65。方案 v2 独立设计复审 Approved。Owner 已授权串行实施和阶段本地提交。[执行台账](2026-11-24_01_execution-loop.md)

目标是在同一绘画流程中快速取色、在画布上调整笔刷、在设置面板中继续精调。范围来自 Owner 的两张示意图和本轮讨论，产品与本机离线范围沿用[产品定位](../../product/PRODUCT_BRIEF.md)。以 Windows 源码 Electron 为本期真实客户端，网页复用组件和现有输入契约。

## P1 Color 面板布局及三种取色模式

- 采用图二的布局结构。前景／背景色块并排于滑条区左侧，色块彼此叠放，滑条旁保留数值，下方取色区域随面板伸缩。沿用现有颜色模式菜单和 Hex 入口。菜单分别表达数值格式与下方取色模式，默认格式沿用现状，默认取色为 RGB 色谱。
- RGB 色谱横向为色相，纵向从白过渡到纯色再到黑，右侧为白／黑快捷取色。色相立方体固定 H，主区横向 S、纵向 B，右侧调 H。亮度立方体固定 B，主区横向 H、纵向 S，右侧调 B。切换模式不改变现有前景／背景颜色。保持色块的目标选择和双击取色弹窗。
- 三种模式共用指针跟踪与坐标夹取，主区和窄条分别持有按下时的操作与前景／背景目标。松手、取消或卸载释放手势并保留最后有效颜色。外部改色时同步显示，失效手势不得重新写入。颜色真值继续写入现有前景／背景状态并实时影响下一笔，统一面板写色入口。保留现有面板调色不追加最近颜色的行为。若复用 editor.setForeground，须支持面板关闭其 recentColors 副作用，避免长拖动挤掉最近色。切换前景／背景分别保留退化颜色下缺失的 H/S，仅用于 UI 补足。现存数值模式继续使用原颜色管理路径。
- 验收覆盖实际面板内点击与拖动、色谱白／纯色／黑采样、两个立方体的轴和窄条、拖到黑或灰后回拉、前景和背景独立、快捷色与 Hex／数值／外部取色同步、窄面板与高度变化。长拖动后既有 recentColors 内容及顺序保持，其他现有取色入口按原规则维护最近色。至少用真实 Electron 的一条完整流程检查颜色影响下一笔和面板布局。
- 依据 [WP 颜色面板](../../../src/ui/panels/ColorPanels.tsx)、[PhotoCraft 滑条与色谱](https://github.com/storytold/photocraft/blob/7c12f647150f8e7b2e07718f7993b1fcaa57fefe/crates/ui-egui/src/panels/color_panel_ui.rs#L320-L395)、[PhotoCraft 立方体](https://github.com/storytold/photocraft/blob/7c12f647150f8e7b2e07718f7993b1fcaa57fefe/crates/ui-egui/src/panels/color.rs#L55-L154)。

## P2 Alt+右键笔刷调节

- Windows 画布中用 Alt+右键拖动实时调节。左减小、右增大直径，上降、下升硬度。拖动起点固定显示笔刷圈，旁边显示实时尺寸与硬度。以屏幕位移和开始时缩放换算直径，显示圈和实际文档像素直径一致。首版对普通 Brush 和支持对应参数的常规 Eraser 开放，铅笔只调尺寸，垂直移动不写不可用的硬度。
- 由画布现有指针入口接管该手势，绑定会话、工具／橡皮擦模式和 pointer ID，遵循 access、会话保护与当前交互边界。松 Alt 不改变已经开始的手势，右键释放结束。组合鼠标按键期间按 `buttons` 状态识别右键已松，整条复合指针序列释放前不得把第二键转给落笔或视图拖动。Esc、失焦、工具／文档切换、弹窗、捕获丢失时停止并保留最后有效参数，丢弃迟到事件。手势不得插入已开始的笔画或视图拖动。仅拦截与已接管手势对应的 contextmenu（含松手后的尾事件），下一次普通右键必须正常开菜单。Alt+左键取色照常工作。
- 参数写入统一走现有笔刷状态入口，尺寸限制在 1–5000 px，硬度限制在 0–100%，与已有快捷键一致。画布反馈、顶栏和面板同步，调节不落笔、不建 Undo 条目、不触发文档 checkpoint。保留用户有效键位与宿主输入隔离。
- 验收覆盖真实指针入口而非直接调用工具对象。水平、垂直、对角移动、至少两档缩放、参数边界、松键次序、取消后立即右键／取色／落笔。比较调节前后图层像素及文档历史。使用隔离 profile 真实 Windows Electron 尽早确认原生 Alt+右键和系统菜单行为。
- 依据 [WP 画布入口](../../../src/ui/CanvasView.tsx)、[PhotoCraft 拖动设计](https://github.com/storytold/photocraft/blob/7c12f647150f8e7b2e07718f7993b1fcaa57fefe/crates/ui-egui/src/tools/brush_resize.rs#L1-L30)。

## P3 Brush Settings 与笔刷快捷键收敛

- 整理现有笔尖、形状动态、散布、纹理和传递参数为可切换的分类，保留现有参数、预设与笔画预览。预览跟随设置，面板在窄 dock 中仍可操作。尺寸统一使用顶栏与快捷键现有的 1–5000 px 范围，硬度统一为 0–100%。统一覆盖顶部控件、Brush Settings、Brushes 尺寸入口、P2 手势及尺寸／硬度快捷键；同一份 BrushSettings 是参数真值。
- 保留 `[` / `]` 调大小和 `Shift+[` / `Shift+]` 调硬度的默认 Action，沿用覆盖、禁用和冲突规则。数字键按当前工具实际使用的参数路由。Brush 与 WP 的三种 Eraser 模式均保留不透明度／流量路由。仅在喷枪积累实际生效的 Brush 里对换普通数字与 Shift 数字，切到 Eraser 后恢复正常分派。独立 Pencil 仅普通数字调不透明度，Shift 数字不写未在该工具顶栏提供的 Flow。该限制仅针对快捷键，现有预设与笔画计算仍按原有方式读取参数。Gradient／Paint Bucket 普通数字走各自不透明度。Move 和选区工具走图层不透明度／填充。只拥有强度、曝光、容差的工具不借数字键修改隐藏笔刷参数或图层。其他已有笔刷类工具以本期实际可用控件和绘制行为核对后保留兼容路由，任务记录列明。
- 通过现有按键分发和 Action 覆盖处理数字输入、文本焦点和工具切换。记录数字序列的具体参数目标，切工具、切文档、改变喷枪模式或开始指针操作使旧目标失效时取消未完成序列，不在延迟提交时重解释为另一参数。保留顶栏和笔刷面板预设入口。
- 验收以用户操作验证手势、键盘、顶栏、Settings 和 Brushes 的尺寸一致，切分类和切预设后现有控制项仍可用。覆盖数字键矩阵、喷枪对换、重绑优先、文本输入、手势冲突和文档历史。复用有意义的输入测试，实际窗口走完选色→调笔→绘画。
- 依据 [WP 笔刷面板](../../../src/ui/panels/MiscPanels.tsx)、[WP 输入分发](../../../src/app/inputDispatch.ts)、[PhotoCraft 数字路由](https://github.com/storytold/photocraft/blob/7c12f647150f8e7b2e07718f7993b1fcaa57fefe/crates/ui-egui/src/input/opacity_keys.rs)。
