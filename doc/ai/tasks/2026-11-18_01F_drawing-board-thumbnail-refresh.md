# 画板返回后的缩略图提速

父任务见[画板工作流](2026-11-18_01_drawing-board-workflow-and-open-performance.md)，调度见[执行台账](2026-11-18_01_execution-loop.md)。

当前基线为 ADA 画板分支 `454fc578`、WP main `3fb4cf8`、embedded `04d1567`。ADA 只在成功返回且最终版本缺图时派生缩略图。上一次 4096 × 2304 本地验证表明可省约 36 MiB 的重复下载。合成和发布仍约 2–3 秒，单次测量不能代表稳定收益。

## F1 复用退出保存缓冲

ADA 画板分支负责。仅退出事务开始后发出的无预览 native 保存可以移交有界上传缓冲。候选随这次退出的生命周期释放，只有成功关闭并匹配最终 binding、revision、content hash 才进入原有缩略图队列。自动保存保持原语义。已自动保存、现有预览、超限、取消、失败、续期和迟到回执继续按原合同处理。源复用失败时可以回到一次正式读取，服务端依旧校验 revision 和 hash。

验收用真实本地浏览器 Worker 和隔离 API 验证路径及请求计数。单独验证退出失败、后台保存零合成、同一最终版本只生成一次、旧候选丢弃、返回不等缩略图。至少报告传输字节及派生耗时的区别。

## F2 直接合成 512 像素

先在 WP 本地材料区用同一固定输入和浏览器比较现有全尺寸合成再缩图与低分辨率合成。比较解码后 RGBA、透明边缘和非线性混合，覆盖 4K 简单与复杂画板、奇数或极端比例、蒙版和调整层。分别采集合成、整体派生和输出尺寸。重复交错运行，处理预热。只有能明确识别适用输入且有足够收益时，才设计产品快路径和回退。若原型无法证明，结束 F2，保留原预览路径。

范围限本地工作树和隔离验证。WP 产品改动由 main 吸收，经 embedded 固定构建给 ADA 使用。正式服务器、收费模型、推送和部署在范围之外。

## 执行记录

独立设计复审（`thumb_review`，基线如上）批准 F1 实施及 F2 隔离原型。Reviewer 指出 WP 在途后台保存可能恰好在 Return 发出后到达，输出本身没有 close intent。Planner 接受，以 Return 候选与最终 binding、revision、hash、checkpoint 的对照为准。原回执未知或候选不符使用正式读取。批准测量 F2 的冷解码、hash、合成、PNG 和总耗时，对照图必须来自当前像素路径。F2 产品接入须单独裁定。

F1 第一轮实现审查指出快速重开并再次返回会重复同版本缩略图，复用派生失败后的正式读取也应重新校验原连接。Planner 接受两项。Coder 增加基于连接及最终版本的在途去重和回退身份校验，Reviewer 独立检查源码及定向测试通过。真实 Chrome 运行 ADA Controller、WP iframe、保存 Worker 和隔离 SQLite，持续编辑与自动保存期间缩略图派生为 0 次。对 4096 × 2304 的画板，退出期间最终保存复用 37,758,132 字节，省去一次正式读取。无退出缓冲时保留一次正式读取。两条路径均在返回后发布一张 512 × 288 PNG，且与正式 revision 和 hash 一致。F1 独立实现通过，Planner 接受，提交 `08a709c1`。Owner 恢复原工作区后，分支和隔离验证材料已迁回 `auto_design_Agent_drawing_board`。

F2 通用 mip 出现明显 Alpha 和叠层差异，排除为默认路径。试验找到一个更窄的 512 直出候选。对单个可见、原点对齐、默认 Normal、无额外蒙版或混合设置的 RGB8 像素图层，可以把占用图块直接缩到输出 Canvas。原型 Chromium 157 的五类候选画板及独立 Electron 的稀疏、密集、P3 样本与当前缩略图逐像素一致。按同一取样核保持图块边界、输出比例与原 ICC、分辨率。候选条件为原尺寸与完整图块网格对齐，同时存在固定整数等比缩放。浏览器／运行环境准入、准确回退和集成验证进入独立产品设计复审。

Reviewer 批准限于已覆盖的 Windows Chrome 157 与 Windows Electron Chromium 152。WP main `596d132` 实现渲染助手。最多允许 4096² 源像素、整个根组仅一个可见像素图层、长边按 2/4/8/16 倍等比例缩到 512。其余由现有路径处理。独立复审通过并复跑定向 22/22。Embedded `50b0846` 采用明确 Chrome 品牌确认和受测 Electron Chromium 版本接入。Reviewer 针对 Chrome 品牌缺失时应走旧路径的意见已修复，独立复跑共 35/35。

最终固定包 `8f03c32852549534c87ef13434d936f2ed6cfdf89ee9357f12eb82b4d077d42e` 共 137 项资源。真实 Windows Chrome 和本机 ADA Electron 44.9.0 的 Worker 均验证单图层透明 4K 直出，多图层和其他浏览器版本回退。同引擎的新旧 PNG 和解码 RGBA 哈希分别完全一致，核对源哈希、显式 sRGB ICC 与分辨率。WP 通用 helper 的本地 Chrome 三轮完整派生中位数，稀疏 4K 972 → 122 ms，密集 4K 1136 → 326 ms。它们是本机 Worker 数据。1920 × 1080 与 3840 × 2160 不满足几何准入条件。

原 ADA 画板工作树用最终固定包运行普通 Chrome，真实 WP 落笔和返回两次均得到最终 revision 2 的 512 × 288 缩略图。两条路径每次一次预览 PUT，两个 Worker 均进入直出。已自动保存路径含打开共两次文档 GET，最终关闭保存复用路径共一次 GET。Worker 渲染和 PNG 编码约 170–210 ms。Web 类型和构建通过，构建后 137 个资源逐项验证。Reviewer 独立批准最终 Worker 和 ADA 固定包，Planner 接受，ADA 本地提交 `728a618b`。生产上屏耗时待用户另行验收。
